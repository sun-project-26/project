# MediSort AI - React Frontend

High-performance HealthTech dashboard and AI waste scanner UI built with React 18, Vite, Tailwind CSS, Lucide React, and Leaflet.

## Features
- **Dark Premium HealthTech Aesthetic**: Glassmorphic cards, glowing borders, and electric indigo highlights.
- **AI Waste Scanner**: Point-of-care waste classification with confidence meters, smart bin routing, and human-review flags.
- **Smart Bins Monitoring**: 4 color categories (Yellow, Red, White, Blue) with load progress bars.
- **Live Vehicle Dispatch Map**: OpenStreetMap Leaflet integration with simulated mobile collection units (`MS-01` to `MS-04`).
- **Cryptographic Traceability Ledger**: Blockchain-inspired SHA-256 digital proof-of-custody audit log.
- **Built-in SIH Demo Mode**: 1-click guided interactive tour for judges.

## Setup & Running Manually
```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev
```

App will run at `http://localhost:5173`.
